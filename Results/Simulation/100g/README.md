# Simulación — Escenario de 100 gCH/día

Esta carpeta contiene los resultados individuales de los diez pacientes adultos virtuales evaluados bajo un escenario de ingesta total de **100 gCH/día**.

Cada ensayo tiene una duración de 24 horas de tiempo simulado.

## Distribución de comidas

| Hora | Ingesta |
|---|---:|
| 06:00 | 30 gCH |
| 13:00 | 40 gCH |
| 19:00 | 30 gCH |
| **Total** | **100 gCH** |

## Organización de resultados

Los resultados se encuentran separados por paciente. Cada carpeta contiene tres secciones:

- **Datos:** señales registradas durante la simulación.
- **Graficas:** representaciones de las variables evaluadas.
- **Metricas:** indicadores de control glucémico y desempeño del controlador.

Esta organización permite consultar y analizar individualmente la respuesta de cada paciente bajo las mismas condiciones experimentales.

Las gráficas consolidadas se encuentran en [Summary/](../Summary/).
