# Controller

Implementación de la estrategia de control desarrollada para la regulación de glucosa.

Esta sección contiene los componentes propios de la estrategia de control implementada en Simulink, incluyendo el acondicionamiento de la señal, el observador de estado extendido (ESO), el controlador ADRC y los mecanismos de seguridad asociados a la administración de insulina.

El simulador UVA/Padova T1DM no se incluye en este repositorio.
